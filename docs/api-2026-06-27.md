## Overview

GrowMate Pods V2 communicates with your cloud server through two HTTPS endpoints:

- **Sensor endpoint** (`POST /api/v2/sensors`) — receives sensor data + actuator state, returns commands
- **Stream registration** (`POST /api/v2/stream/register`) — registers the live H.264 stream URL

V2 uses **live H.264 streaming** via rpicam-vid instead of still JPEG uploads.
No camera endpoint, no image uploads, no EXIF metadata.

### Communication Flow

```
┌─────────────┐                    ┌─────────────┐
│  GrowMate   │                    │  Your API   │
│    Pods     │                    │   Server    │
└──────┬──────┘                    └──────┬──────┘
       │                                  │
       │  POST /api/v2/sensors (JSON)     │
       ├─────────────────────────────────>│
       │  Response: commands[] (JSON)     │
       │<─────────────────────────────────┤
       │                                  │
       │  POST /api/v2/stream/register    │
       ├─────────────────────────────────>│
       │  Response: { success }           │
       │<─────────────────────────────────┤
       │                                  │
```

### Configuration

Set your API endpoints in `/etc/growmate/config.yaml`:

```yaml
api:
  sensor_url: "https://growmate.bond/api/v2/sensors"
  stream_register_url: "https://growmate.bond/api/v2/stream/register"
  timeout_sensor: 30.0
  timeout_stream_register: 10.0
```

## Sensor Data Upload

### Endpoint

**URL:** `api.sensor_url` from config

**Method:** `POST`

**Content-Type:** `application/json`

**Frequency:** Every `intervals.sensor_reading` seconds (default 60, configurable 10–300)

### Request Headers

```
Content-Type: application/json
x-api-key: <DEVICE_API_KEY>
X-Correlation-Id: <uuid>
```

### Request Body

```json
{
  "deviceId": "growmate-b827eb123456",
  "firmwareVersion": "2.0.0",
  "currentState": {
    "pumpEnabled": false,
    "lightEnabled": false,
    "fertilizerEnabled": false,
    "pesticideEnabled": false,
    "tankSwitchOpen": false,
    "drawerSwitchOpen": false,
    "batteryCurrent": 0
  },
  "sensors": [
    {"kind": "soil", "value": 45, "unit": "%", "raw": 29491},
    {"kind": "light", "value": 78, "unit": "%", "raw": 51118},
    {"kind": "water", "value": 92, "unit": "%", "raw": 60292},
    {"kind": "temperature", "value": 25.3, "unit": "C"},
    {"kind": "air", "value": 60.5, "unit": "%"}
  ]
}
```

### Field Descriptions

| Field | Type | Description |
|-------|------|-------------|
| `deviceId` | string | Unique device identifier |
| `firmwareVersion` | string | Semantic version (currently `2.0.0`) |
| `currentState` | object | Current actuator and switch states |
| `currentState.pumpEnabled` | boolean | Water pump relay active |
| `currentState.lightEnabled` | boolean | Always `false` (V2 has no grow light) |
| `currentState.fertilizerEnabled` | boolean | Fertiliser solenoid relay active |
| `currentState.pesticideEnabled` | boolean | Pesticide solenoid relay active |
| `currentState.tankSwitchOpen` | boolean | Tank lid limit switch (NC→HIGH=open) |
| `currentState.drawerSwitchOpen` | boolean | Drawer limit switch (NC→HIGH=open) |
| `currentState.batteryCurrent` | number | ACS712 current in mA (neg=discharge) |
| `sensors` | array | 5 sensor readings (see below) |

**Sensor kinds:**

| `kind` | Unit | Range | Source |
|--------|------|-------|--------|
| `soil` | % | 0–100 | ADS1115 ch3 |
| `light` | % | 0–100 | ADS1115 ch1 |
| `water` | % | 0–100 | ADS1115 ch2 |
| `temperature` | C | -40–125 | DHT22 |
| `air` | %RH | 0–100 | DHT22 |

- Analog sensors (`soil`, `light`, `water`) include a `raw` field with the 16-bit ADC value (0–65535)
- DHT22 sensors do not include `raw`
- All 5 sensor kinds are sent in every POST

### Response

**Success (200 OK):**

```json
{
  "success": true,
  "updated": 5,
  "commands": [
    {"kind": "pump", "durationMs": 8000},
    {"kind": "fertilizer", "durationMs": 10000}
  ]
}
```

**No commands:**

```json
{
  "success": true,
  "updated": 5,
  "commands": []
}
```

## Stream Registration

Called once at startup after Tailscale is connected and rpicam-vid is listening.

### Endpoint

**URL:** `api.stream_register_url` from config

**Method:** `POST`

**Content-Type:** `application/json`

### Request

```json
{
  "deviceId": "growmate-b827eb123456",
  "streamUrl": "tcp://100.x.x.x:8554"
}
```

`streamUrl` format: `tcp://<Tailscale IP>:<camera.port>`.

### Response

```json
{
  "success": true,
  "streamId": "growmate-b827eb123456"
}
```

Retries up to `stream_registration.max_attempts` (default 10) with exponential back-off.

## Command Format

Commands are returned in the sensor upload response and executed immediately.
The server should clear commands after each successful sensor POST.

### Pump

Activates the water pump relay for a duration.

```json
{"kind": "pump", "durationMs": 5000}
```

- `durationMs`: 1–60000 (1 second – 60 seconds)

### Fertiliser

Activates the fertiliser solenoid (pump is ALSO activated simultaneously).

```json
{"kind": "fertilizer", "durationMs": 10000}
```

### Pesticide

Activates the pesticide solenoid (pump is ALSO activated simultaneously).

```json
{"kind": "pesticide", "durationMs": 10000}
```

### Execution Rules

1. If `fertilizer` or `pesticide` is commanded, the server MUST also include a `pump` command in the same response — the pump carries the chemical through the valve.
2. If only `pump` is commanded = plain watering (no chemicals).
3. If multiple `durationMs` values differ, all relays hold for the **maximum** duration.
4. After execution, the next POST's `currentState` reflects actual relay states.
5. `light` commands are **ignored** (V2 has no grow light).

### Multiple Commands

```json
{
  "commands": [
    {"kind": "pump", "durationMs": 10000},
    {"kind": "fertilizer", "durationMs": 10000}
  ]
}
```

## Error Handling

### HTTP Status Codes

| Code | Meaning | Action |
|------|---------|--------|
| 200 | Success | Process commands |
| 400 | Bad Request | Check request format |
| 401 | Unauthorized | Check `x-api-key` |
| 403 | Forbidden | Check API key permissions |
| 404 | Not Found | Check endpoint URL |
| 429 | Too Many Requests | Back off (rate-limit) |
| 500 | Server Error | Retry with back-off |

### Retry Behaviour

GrowMate automatically retries failed uploads:

1. **Exponential back-off:** 1 s, 2 s, 4 s, 8 s, 16 s, 32 s (configurable via `retry.*`)
2. **Jitter:** ±25% random variation (configurable)
3. **Max attempts:** 6 (configurable)
4. **Circuit breaker:** Opens after 5 consecutive failures (configurable)

### Offline Queue

When uploads fail, data is stored locally in SQLite:

- **Sensor data:** Up to `queue.max_sensor_entries` entries
- **Storage:** `queue.db_path` SQLite database
- **Auto-cleanup:** Entries older than `queue.max_age_hours` are deleted
- **Drain:** Queue drains automatically when connectivity returns

## Example Server

### Python (Flask) — Minimal

```python
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route('/api/v2/sensors', methods=['POST'])
def sensors():
    data = request.json
    device_id = data['deviceId']
    sensors = data['sensors']
    state = data['currentState']

    soil = next(s['value'] for s in sensors if s['kind'] == 'soil')

    commands = []
    if soil < 30:
        commands.append({'kind': 'pump', 'durationMs': 5000})

    return jsonify({'success': True, 'updated': len(sensors), 'commands': commands})

@app.route('/api/v2/stream/register', methods=['POST'])
def register_stream():
    data = request.json
    device_id = data['deviceId']
    stream_url = data['streamUrl']
    print(f"Stream registered: {device_id} @ {stream_url}")
    return jsonify({'success': True, 'streamId': device_id})
```
